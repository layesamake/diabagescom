# Diaba Gescom — Messages audio à enregistrer (langue locale)

Oct 18, 2026 · @Etienne Samaké

## Mode d'emploi

L'administrateur enregistre la voix **au moment de configurer sa boutique** (étape 2 des Premiers pas). Il choisit une seule langue locale pour toute l'entreprise (wolof, pulaar, bambara, sérère…) et y dit chaque phrase : **153 enregistrements** (123 phrases + 30 mots pour les chiffres). Les textes à l'écran restent en français. **Le haut-parleur n'apparaît qu'à côté des phrases déjà enregistrées** : pas d'enregistrement, pas d'icône.

- **Le code + la langue donnent le nom du fichier** : VEN-05\_wo (wolof), VEN-05\_ff (pulaar), VEN-05\_bm (bambara).
- **Les mots entre accolades changent à chaque fois.** L'application les remplace :
  - {montant}, {nombre}, {heure} : assemblés avec les mots de la section Chiffres et montants.
  - {article} et {client} : le nom dit au micro quand on crée l'article ou le client.
- **Pour bien enregistrer** : endroit calme, téléphone à 20 cm de la bouche, voix lente et naturelle, moins de 5 secondes par phrase.
- **Dites la phrase comme à un client au marché**, sans traduire mot à mot. Pour les boutons (Vendre, Caisse…), dites le mot courant dans la langue.
- **Changer de langue plus tard** : les anciens enregistrements sont gardés, mais il faut enregistrer les 153 dans la nouvelle langue ; d'ici là, les haut-parleurs des phrases manquantes disparaissent.

## Chiffres et montants (30)

Ces 30 mots français servent de modèle : avec eux, on peut dire tous les montants et toutes les heures. Exemple : 45 750 F = quarante + cinq + mille + sept + cent + cinquante + francs. Un fichier par mot.

| Code | Mot (français) |
| --- | --- |
| CHF-01 à CHF-17 | zéro, un, deux, trois, quatre, cinq, six, sept, huit, neuf, dix, onze, douze, treize, quatorze, quinze, seize |
| CHF-18 à CHF-23 | vingt, trente, quarante, cinquante, soixante, quatre-vingt |
| CHF-24 | et (vingt et un) |
| CHF-25 | cent |
| CHF-26 | mille |
| CHF-27 | million |
| CHF-28 | francs |
| CHF-29 | heures |
| CHF-30 | minutes |

**Dans la langue locale, les nombres se construisent autrement.** En wolof par exemple, 6 se dit juróom benn (« cinq-un »). La liste des mots et la façon de les assembler sont à fixer avec l'administrateur pour la langue choisie, avant d'enregistrer. Le nombre de mots peut donc être différent de 30 ; le développeur code ensuite ces règles.

- [ ] Décider si l'application dit les montants en francs ou dans l'unité du marché (en wolof, le dërëm : 1 dërëm = 5 F, donc 1 000 F = 200 dërëm).
